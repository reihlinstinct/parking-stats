# Security policy

Report vulnerabilities privately via GitHub's private vulnerability
reporting on this repository, or by email to the maintainer listed on the
repository profile. Do not open public issues for security reports.

## Privacy scope

This repository must only ever contain **aggregated** statistics. Raw
municipal exports, license plates, reporter names, phone numbers and case
descriptions are out of scope by design; the CI privacy scan blocks them.
If you find private data here, report it immediately through the same
private channels so it can be removed and history purged.
