# parking-stats

Aggregate-only public statistics from Jerusalem 106 parking reports.

This repository publishes **aggregates only**: counts by month, week,
category, street, neighborhood and hotspot, plus closure-time summaries.
It must never contain raw export data, license plates, names, case
descriptions or any per-case detail. A CI privacy scan enforces this on
every push and PR.

Generated by `p106-stats` from
[parking-report-helper](https://github.com/reihlinstinct/parking-report-helper).

## Publishing flow

`p106-stats build` runs **locally** on raw exports (they never leave the
machine and never enter this repo). Its aggregate output directory is then
published with:

```sh
python -m parking_stats.publish OUTPUT_DIR --label "..."
# or, once installed: parking-stats-publish OUTPUT_DIR
```

The publisher re-scans every file, the `--label` text and the rendered
landing page with the privacy rules and refuses to publish on any
finding; only then does it copy `report.html` and `data/` into
`public/`, which GitHub Pages serves. The live site currently shows
**synthetic demo data** generated from test fixtures.

### What the scanner detects

- License plates: dashed/spaced forms with `- . / _`, whitespace or
  Unicode dashes (U+2010-U+2015, U+2212) as separators, repeats allowed;
  and compact 7-8 digit forms, each digit optionally followed by one
  separator (so a stray space inside the number is caught too). ISO
  dates are excluded from the compact rule.
- Israeli mobile numbers: `05X` / `+972` / `972` / `00972` prefixes, an
  optional `(0)` after an international prefix, and any mix of dashes,
  spaces, dots, slashes or parentheses between the digit groups.
- Raw municipal export keys (`description`, `caseId`, `case_number`,
  `ClosedDateIncident`), case-insensitive, quoted or not, followed by
  `:` or `=`, and the same names as CSV header columns.

All matching runs on normalised text: NFKC folding (full-width digits
become ASCII), zero-width characters and BOM removed, no-break spaces
converted to plain spaces.

### Scanner limitations (accepted)

Matching is per line: a plate or key split across a line break is not
detected. The compact plate rule also matches bare 7-8 digit numbers
(aggregate outputs never contain any, so a hit is worth a human look
rather than a waiver).
